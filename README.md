# class-imbalance-project

Исследование и реализация **предметно-ориентированных подходов** к задачам **классификации с дисбалансом классов** (перевыборка, cost-sensitive обучение, калибровка порога, метрики для редкого класса, MLOps-протокол экспериментов).

**Автор:** Цыганцов Артём Сергеевич, МО26-1м, ОП «Инженер машинного обучения», Финансовый университет.

**Научный руководитель:** д.т.н., проф. Емельянов Виталий Александрович.

## Цель

Разработать предметно-ориентированный подход к обучению моделей при сильном перекосе классов и подтвердить его экспериментально на прикладных и открытых данных.

## Состав репозитория

| Компонент | Описание |
|-----------|----------|
| `main.tex`, `parts/`, `include/` | Текст работы (введение, 3 главы, заключение, список источников) |
| `references.bib` | Библиография |
| `docs/reference/` | Методичка, заявление на тему (локальные материалы) |

## Структура работы

1. Обзор методов и требований к решению при дисбалансе классов.
2. Проектирование и реализация предметно-ориентированного подхода.
3. Эксперименты, сравнение с baseline и анализ воспроизводимости.

PDF собирается из корня: `make` (XeLaTeX).
