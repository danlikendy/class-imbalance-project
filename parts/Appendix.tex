\section*{Приложение А}
\addcontentsline{toc}{section}{Приложение А. Репозиторий с исходным кодом и материалами проекта}
\label{sec:appendix-a}

Исходный код программной реализации, конфигурации экспериментов и вспомогательные материалы размещаются в репозитории разработки ВКР (каталог \texttt{class-imbalance-project}); публикация на GitHub выполняется автором по согласованию с организацией-партнёром.

Заявление о закреплении темы ВКР, методические рекомендации кафедры и черновые материалы хранятся в каталоге \texttt{docs/reference/} данного репозитория.
